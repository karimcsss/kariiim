# Projet Conception de Systèmes d'Information (UML)

## 📋 Vue d'ensemble

Ce repository contient l'ensemble des ressources pédagogiques pour un projet de conception de systèmes d'information en UML, destiné aux étudiants de niveau L2.

**Durée** : 8 semaines  
**Type** : Projet en groupe  
**Objectif** : Maîtriser la conception de SI avec UML (cas d'utilisation, séquence, classes)

## ✅ Conseils pour réussir

1. **Commencez tôt** : Ne pas attendre la dernière minute
2. **Travaillez régulièrement** : Avancement progressif chaque semaine
3. **Communiquez** : Échangez avec votre encadrant
4. **Soyez cohérents** : Vérifiez la cohérence entre tous les livrables

## 🎯 Objectifs pédagogiques

À la fin de ce projet, les étudiants seront capables de :

- ✅ Analyser un besoin métier et délimiter un système d'information
- ✅ Identifier les acteurs et les besoins fonctionnels/non fonctionnels
- ✅ Créer des diagrammes de cas d'utilisation UML
- ✅ Modéliser les interactions avec des diagrammes de séquence
- ✅ Concevoir un diagramme de classes métier
- ✅ Assurer la cohérence entre tous les artefacts UML
- ✅ Présenter et défendre leurs choix de conception
