# Semaine 1 – Lancement & cadrage du projet

## 🎯 Objectifs pédagogiques

- Comprendre le contexte métier du projet affecté
- Apprendre à délimiter un système d'information
- Identifier les parties prenantes et leurs rôles
- Établir le périmètre du projet

---

## 📋 Travaux à réaliser

### 1. Analyse du sujet

Commencez par lire attentivement le sujet qui vous a été affecté. Posez-vous les questions suivantes :
- Quel est le domaine métier ?
- Quel problème cherche-t-on à résoudre ?
- Quels sont les objectifs principaux du système ?

### 2. Identification des acteurs

**Acteurs** : Personnes, organisations ou systèmes externes qui interagissent avec le système.

Types d'acteurs à identifier :
- **Acteurs principaux** : utilisateurs directs du système
- **Acteurs secondaires** : systèmes ou services externes
- **Acteurs administratifs** : gestionnaires, administrateurs

### 3. Définition des objectifs du système

Listez les objectifs SMART (Spécifiques, Mesurables, Atteignables, Réalistes, Temporels) :
- Que doit permettre le système ?
- Quels processus métier seront supportés ?
- Quelles sont les fonctionnalités essentielles ?

### 4. Délimitation du périmètre

**Ce qui est inclus dans le système** :
- Fonctionnalités principales
- Processus couverts
- Utilisateurs concernés

**Ce qui est exclu du système** :
- Fonctionnalités hors périmètre
- Interfaces non prises en compte
- Cas d'usage reportés

### 5. Clarification du vocabulaire métier

Créez un glossaire des termes métier :

| ... | ... | ... |

## 📄 Livrable 1 (partiel) : Cahier des charges

**Format** : Document PDF ou Markdown  
**Contenu minimal** :

1. **Page de garde**
   - Titre du projet
   - Noms des membres du groupe
   - Date

2. **Introduction**
   - Contexte du projet
   - Problématique

3. **Présentation générale**
   - Objectifs du système
   - Parties prenantes

4. **Périmètre du projet**
   - Inclusions
   - Exclusions

5. **Acteurs identifiés**
   - Liste des acteurs avec descriptions

6. **Glossaire métier**
   - Termes clés avec définitions

**Template** : Utilisez le [modèle de cahier des charges](../templates/Cahier_des_charges.md)

## 💡 Conseils

1. **Rencontrez votre client/sponsor** (si applicable) pour valider votre compréhension
2. **Documentez vos hypothèses** si certains éléments sont ambigus
3. **Restez réaliste** dans la définition du périmètre
4. **Utilisez des exemples concrets** pour illustrer le contexte
