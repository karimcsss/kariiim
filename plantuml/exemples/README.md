# Exemples Simples PlantUML

Ce dossier contient des exemples minimalistes pour débuter avec PlantUML.

## 🎯 Pour Qui ?

Ces exemples sont parfaits si :
- Vous découvrez PlantUML
- Vous voulez un template de départ simple
- Vous apprenez les bases d'UML

## 📁 Fichiers

### 1. `exemple_simple_cas_utilisation.puml`
Le diagramme de cas d'utilisation le plus simple possible :
- 1 acteur
- 3 cas d'utilisation
- Relations basiques
- 1 note

### 2. `exemple_simple_sequence.puml`
Le diagramme de séquence le plus simple possible :
- 1 acteur
- 2 participants
- 4 messages
- Numérotation automatique

### 3. `exemple_simple_classes.puml`
Le diagramme de classes le plus simple possible :
- 2 classes avec attributs et méthodes
- 1 relation avec multiplicité
- 1 note

## 🚀 Démarrage Rapide

1. **Copiez** un de ces exemples
2. **Modifiez** les noms pour votre projet
3. **Ajoutez** vos éléments
4. **Visualisez** avec PlantUML

## 💡 Progression Suggérée

### Étape 1 : Testez les exemples
Ouvrez chaque exemple et générez le diagramme pour voir le résultat.

### Étape 2 : Modifiez légèrement
Changez un nom, ajoutez un élément, supprimez une ligne.

### Étape 3 : Créez le vôtre
Partez d'un exemple et adaptez-le complètement à votre projet.

### Étape 4 : Consultez les exemples complets
Une fois à l'aise, regardez les diagrammes complets dans le dossier parent.
